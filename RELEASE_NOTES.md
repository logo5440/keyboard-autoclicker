## Keyboard Autoclicker 1.9.1

Press or hold keyboard keys automatically – like OP Auto Clicker, but for the keyboard. Windows 10 and 11 (64-bit).

### Downloads
- **KeyboardAutoclicker_Setup.exe** – installer (Start menu entry, optional desktop shortcut and autostart, uninstall via Windows Settings).
- **KeyboardAutoclicker_Portable.exe** – portable version, runs without installation.

The files are not code-signed. If Windows SmartScreen shows "Windows protected your PC", click **More info → Run anyway**.

### Highlights
- Click mode and hold-key mode, key combinations such as `ctrl+c`
- Global start/stop hotkey (default `F6`), start delay with countdown
- Press counter, running time, stop after X minutes
- Emergency stop with `Esc` or by pushing the mouse into a screen corner
- Light/dark/system theme, accent color, transparent or picture background
- Resizable window, size steps, compact view, always on top

### Fixed in 1.9.1
- The window did not appear with Python 3.15 / Tk 9.0 (endless layout loop).
- Errors are now saved to `%APPDATA%\KeyboardAutoclicker\error.log`.
